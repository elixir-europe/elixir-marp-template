# Logo usage

This folder also contains trademarked brand assets. When in doubt, check the source, not this file.

## `elixir-logo-standard.png`, `elixir-logo-white.png`

Obtained from ELIXIR Intranet, fine for using in your own ELIXIR-related presentations

## `linkedin-logo.png`

From https://brand.linkedin.com/downloads.

LinkedIn's brand guidelines (<https://brand.linkedin.com/in-logo>) permit an
unmodified `[in]` logo, in one of the three approved colors (blue/black/
white), used in a lineup of social media icons or as a hyperlink to a
profile/company/group page.


## `bluesky-logo.png`

From https://bsky.social/about/blog/press-faq

Per Bluesky's branding guidelines
(<https://bsky.social/about/support/branding>), no permission is needed to
use the Bluesky butterfly as a social media icon, provided the usage
follows the conditions on that page (e.g. using the mark unaltered and not
implying endorsement by Bluesky).
